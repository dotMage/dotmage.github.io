A small follow-up to 2.0, all from real team-usage friction.

## Fixes

- **Servers advertise their name.** Set `DOTMAGE_SERVER_NAME=work` at deploy and every
  client that joins picks it up automatically — no more `dmage server rename` after an
  invite. Works on the installer: `... | DOTMAGE_MODE=team DOTMAGE_SERVER_NAME=work bash`.
- **`dmage clean --server <name>`** wipes a single server (key + tokens + config entry).
  The global `dmage clean` now warns loudly that it removes *every* server, and points
  you at the scoped command — no more nuking your personal vault while cleaning up work.
- **Web admin shows who you are.** The header displays your real user, role and device
  instead of a hardcoded "admin", and the browser tab + header carry the server's name so
  several open team panels are finally distinguishable.

## Исправления

- **Серверы объявляют своё имя.** Задайте `DOTMAGE_SERVER_NAME=work` на деплое, и каждый
  клиент при вступлении подхватит его сам — больше не нужен `dmage server rename` после
  инвайта. Работает в инсталлере: `... | DOTMAGE_MODE=team DOTMAGE_SERVER_NAME=work bash`.
- **`dmage clean --server <name>`** стирает один сервер (ключ + токены + запись конфига).
  Глобальный `dmage clean` теперь громко предупреждает, что удалит *все* серверы, и
  подсказывает точечную команду — больше не снесёте личное хранилище, убираясь в рабочем.
- **Веб-админка показывает, кто вы.** В шапке — ваш реальный пользователь, роль и
  устройство вместо захардкоженного «admin», а вкладка браузера и шапка несут имя
  сервера, так что несколько открытых командных панелей наконец различимы.

## Чейнджлог

- `dmage clean --server <name>` для точечного удаления; громкое предупреждение у глобального clean.
